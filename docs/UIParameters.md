## 链环与反射

- `src/ui/assets/bridge-reference.png` 保留确认图原始像素，不再重新生成链环。
- `.fc-art` 通过 CSS 背景定位显示原图 x1134 / y243 / 280×208 区域；默认比例 0.7357，显示约 206×153px。
- 背景尺寸为 `1512×比例` / `1040×比例`，偏移为 `-1134×比例` / `-243×比例`；环的形态、高光、接触反射与确认图一致。
- 裁片采用 multiply 混合；蓝环、紫环、反射分别使用椭圆遮罩叠加，消除矩形裁片边缘；裁片中的分隔线与模型区上边线对齐。
- 遮罩：蓝环半径 36% / 35%、中心 31% / 30%、90% 内保留原像素；紫环半径 33% / 30%、中心 63% / 48%、82% 内保留；反射半径 46% / 27%、中心 52% / 76%、40% 至 95% 衰减。
- 保留原图的反射与局部染光，不用重新镜像一张链环制造另一种反射。

## 缩小窗口与平台

- 900px 以下：侧栏 164px、主内容内边距 24px、卡片 20px 内边距；操作按钮 128×40px、间隔 12px；链环比例 0.60，仍与分隔线对齐。
- 最小窗口 760×650：控件可换行，设置可滚动，保存栏、错误定位和浮层不被裁切；不缩放整个 DOM，避免文字模糊。
- macOS 原生窗口控制、Windows 原生标题栏、系统字体与现有快捷键继续使用系统能力；共用一份页面代码。
- 减少透明度时使用同色系实底，关闭柔光叠加与半透明面板；减少动态效果时保留原有动效回退。
- 原生窗口外阴影、系统控件、字体抗锯齿与动态业务文字不作为概念图逐像素一致的承诺；不能以这些差异掩盖页面光影未实现。
